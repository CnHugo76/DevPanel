# v0.3：快捷操作与 Maven

> 仅当 `devpanel --help` 的用法行里有 `action` / `maven` 时适用。稳定版 v0.2 没有这些命令。

快捷操作和 Maven 运行都是**任务运行**：跑完即结束，退出码 0 → `succeeded`，非 0 或信号 → `failed`；另有 `cancelled`、`timed-out`、`unknown`。它们由 daemon 托管，用户在面板里看到同一份输出、可以取消。结果以 `--json` 输出里任务运行的 `state` 为准。

## 快捷操作

项目登记的一键命令，例如 `clean install -DskipTests -pl backend -am`、`pnpm build`、数据库迁移脚本。在配置里写在 `actions` 数组中，和 `services` 平级：

```jsonc
"actions": [
  {
    "id": "install-backend",   // 格式同服务 ID；与服务 ID 分属不同命名空间
    "name": "clean install -DskipTests · backend",   // 按钮文字
    "description": "只构建后端及其依赖模块，跳过测试",
    "cwd": ".",
    "command": ["./mvnw", "clean", "install", "-DskipTests", "-pl", "backend", "-am"],
    "timeoutSec": 1800,                 // 可选，1–86400，超时按取消处理
    "confirmWhenServicesRunning": true  // 可选，服务运行时先确认
  }
]
```

`command`、`cwd`、`env`、`${key}` 选项引用的规则与服务相同（见 [config.md](config.md)）。接入或更新项目时，把用户反复手敲的固定组合登记为快捷操作；注册和更新都不会执行它们。

```bash
devpanel action list <project-id> --json
devpanel action run <project-id> <action-id> --json
```

- 同一快捷操作同一时刻最多一个运行；再次运行返回现有运行（`created: false`），不同快捷操作可以并行。
- `confirmWhenServicesRunning` 为 true、且项目有服务在运行时，先问用户再运行；daemon 本身不拦截。

## Maven

v0.4.1 可按 [配置](config.md) 明确登记多个 Maven 工程；旧配置在项目根有 `pom.xml` 时可用。daemon 自己构造命令（项目根有可执行的 `mvnw` 时用它，否则用 PATH 中的 `mvn`），只接受下面这些参数：

```bash
devpanel maven modules <project-id> [--maven-project <id>] --json
devpanel maven run <project-id> [--maven-project <id>] [--module <id>] [-P <profile>]... [--skip-tests] [--offline] [--also-make] <goal>... --json
```

- 新版 `--maven-project` 取配置的工程 ID；多个工程时必填，未知 ID 不回退。旧版 help 不含该开关时不传。wrapper 和执行目录相对所选工程根。
- `--module` 取 `maven modules` 返回的模块 `id`（相对所选工程根的目录，根模块为 `.`）；`-P !id` 表示停用该 profile。
- 同一项目同一时刻最多一个 Maven 运行：已有时返回 `TASK_RUNNING`，`error.details.runId` 是正在跑的那次。等它结束，或问用户是否取消。
- 模块、goal、profile 不合法 → `MAVEN_INVALID`，`details` 指明字段。

## 日志与取消

```bash
devpanel logs <project-id> --run <run-id> --tail 200
# v0.4 优先摘要；后续同一运行使用 --after-seq <lastSeq>
devpanel logs <project-id> --run <run-id> --digest --json
devpanel task cancel <run-id> --json
```

`run-id` 来自 `action run` / `maven run` 的输出。取消先发 SIGTERM；超过等待时间仍未退出时 `cancelTimedOut` 为 true，此时向用户报告，由用户决定是否 `task cancel <run-id> --force`。

执行超时退出码为 10，读取任务状态与摘要并报告，不自动重跑。

`action run` / `maven run` 默认等运行结束；构建可能很久，较长的任务用 `--no-wait` 拿到 `run-id`，再用 `logs --run` 查看进度。

## Git

CLI 不提供 Git 命令，面板里的暂存、提交、储藏只接受人在面板里操作；你照常在终端使用 `git`。
