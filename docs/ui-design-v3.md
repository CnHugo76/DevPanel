# DevPanel 原生界面设计 v3（第 2 稿：Maven 视图、快捷操作、Git）

> 产品依据：[product-design-v0.3.md](product-design-v0.3.md)。视觉参考：[ui-mockup-v3.html](ui-mockup-v3.html)。
> 只写相对 [ui-design-v2.md](ui-design-v2.md) 的新增与变化；v2（含“详情模式与按需说明”补充）中未被修改的规则继续有效。数据只来自契约 v1.2（`contract/CHANGES.md` 的 C、D 两条）。

## 1. 检查器的对象：服务或项目
- `selection` 从“服务”扩展为“服务或项目”。点击项目名（或项目卡片 ⋯ →“项目详情”）打开**项目检查器**；点击服务行仍打开服务检查器。
- 项目检查器标签：**Maven**（项目根有 `pom.xml` 时才有）、**快捷操作**、**Git**、**选项**。记住每个项目上次所在的标签。
- 项目检查器默认宽 580，可拖动 380–640；打开时总览进入紧凑模式，并隐藏项目卡片标题行的 CPU · 内存合计。
- 详情模式：左侧导航中每个项目的第一行是“项目”入口。服务检查器不变。

## 2. 项目卡片
- **Git 摘要**（标题行，路径之后）：`⎇ main · 5 处改动 · ↑2`；无改动“无改动”；分离 HEAD 显示短 SHA；非仓库不显示。点击打开项目检查器的 Git 标签。
- **快捷操作行**（选项行下方，没有快捷操作且不是 Maven 项目时不显示）：
  - 前缀“快捷操作”，每个快捷操作一个按钮：空闲 `▶ clean install -DskipTests`（按钮文字为 AI 起的名称，悬停显示完整命令）；运行中转圈 + 已用时间 + ■；上次结果小字（`✓ 1m12s` / `✕ 退出码 1`）。
  - Maven 项目在行末多一个“Maven…”按钮，打开 Maven 标签；如果有 Maven 运行正在进行，这个按钮显示为运行状态（`● Maven: clean install · 0:42 ■`）。
  - 超过 6 个时折行或收进“全部…”。

## 3. 项目检查器 · Maven（对标 IDEA Maven 工具窗口的基础部分）

### 3.1 工具栏（顶部一行）
`↻ 重新加载` · `▶ 运行`（运行选中的阶段）· `■ 取消` · 分隔 · `跳过测试` 开关 · `离线` 开关 · `-am` 开关 · 分隔 · `运行 Maven 目标…` · `存为快捷操作`。开关状态按项目记住。

### 3.2 树（中部，可滚动）
```
▾ m regpulse (pom)                     ← 根模块；名称后灰色 groupId:artifactId
  ▾ Lifecycle
      clean  validate  compile  test  package  verify  install  site  deploy   ← 每个阶段一行
  ▸ m backend (jar)
  ▸ m frontend (pom)
▾ Profiles
   ☐ dev   ☑ local-db   ⊘ integration      ← 三态：默认 / 启用 / 禁用(!)
```
- 单击选中、⌘ 点击多选（多选只在同一模块内有效）；双击运行；Enter 运行选中。
- 解析失败的模块标红，悬停显示原因；父 POM 不在项目内的模块标注“父 POM 在项目外”。
- 右键菜单：运行、运行并跳过测试、复制命令、存为快捷操作。

### 3.3 命令预览（树下方一行，等宽）
始终显示即将执行的完整命令，例如 `./mvnw -pl backend -am -DskipTests -P local-db,!integration clean install`，可选中复制。没有选中阶段时显示“选择阶段后双击运行”。

### 3.4 输出（下半部分）
- 复用 v2 日志视图（ANSI、搜索、跟随、新日志提示、5 万行上限、堆栈折叠）；运行切换：本次 / 上一次 / 更早（最多 5 次）。
- 底部状态：运行中“运行中 · 时长 · CPU · 内存（N 个进程）”；结束“成功 / 失败（退出码）/ 已取消 / 超时 · 用时”。
- 已有 Maven 运行时，再次运行被拒绝：提示“reg-radar 已有 Maven 运行（clean install · 0:42），先等待或取消”。

### 3.5 运行前确认
阶段包含 `clean` 且项目有服务在运行时确认：“运行 clean？reg-radar 有 2 个服务正在运行，clean 会删除 target/，正在运行的服务可能出错。”显示完整命令，按钮“取消”“仍然运行”。

## 4. 项目检查器 · 快捷操作
- 列表：名称、说明（次要色）、命令（等宽，`${key}` 原样，悬停显示替换后）、上次结果、▶ / 取消 / 强制取消；⋯：编辑、删除（运行中禁用）、复制命令。
- 选中一项，下方显示其输出（同 §3.4）。
- 运行前确认：快捷操作标注了“服务运行时需确认”且有服务在运行时，用其说明文字确认。
- 添加 / 编辑：项目编辑 sheet 的“快捷操作”分区（名称、ID、说明、工作目录、命令及预览、环境变量、停止等待、最长运行时间、“服务运行时需确认”）。
- 通知：运行结束且窗口不在前台时通知；用户主动取消不通知。

## 5. 项目检查器 · Git（列表优先）

### 5.1 Git 页（不含差异预览）
自上而下：
1. 分支行：`⎇ main · 领先 origin/main 2 个提交`、“刷新”。
2. 改动文件列表，分组：已暂存 / 未暂存 / 未跟踪 / 冲突（有时显示）。每组标题右侧“全部暂存 / 全部取消暂存”。每行：复选框（勾选 = 已暂存）、状态字母（M / A / D / R / ? / U）、文件名（正常色）+ 所在目录（灰色）、`+N −M`、敏感文件标记 `⚠ 可能含密钥`。行可多选（⇧ / ⌘），对选中项批量暂存 / 取消暂存。
3. 储藏列表（有储藏时显示，可折叠）：说明、`stash@{n}`、分支、时间、“恢复 ▾”（pop / apply）。
4. 提交区：提交信息、“修改上一次提交”、“储藏…”、“提交 N 个文件”。

单击文件行 = 选中；**双击或 Enter = 打开差异窗口**；行尾的 `↗` 按钮也可打开。

### 5.2 差异窗口（独立窗口）
- 标题：`Regulations.tsx — reg-radar（未暂存）`；工具栏：`↑ ↓` 上一个 / 下一个改动、`← →` 上一个 / 下一个文件（按列表顺序）、并排 / 统一切换、“暂存此文件 / 取消暂存”、“在 Finder 中显示”。
- 并排视图：左侧为基准（已暂存的差异以 HEAD 为基准；未暂存的以暂存区为基准），右侧为新内容；**显示整个文件**，改动块高亮（删除红底、新增绿底、修改行内高亮变化部分），未改动的长段落折叠为“… 展开 120 行未改动 …”。
- 统一视图：同一面板，带新旧行号。
- 二进制文件：“二进制文件已修改（旧 12 KB → 新 14 KB）”；超过 5,000 行或 2 MiB：显示前部并提示“差异过大，已截断”。
- 文件在窗口打开期间又被修改：顶部提示“文件已变化 · 刷新”。
- 可同时打开多个差异窗口；同一文件同一侧重复打开时激活已有窗口。

### 5.3 交互与错误（同第 1 稿）
敏感文件提交前警告；提交结束后显示钩子输出，失败时红色横幅并保留输出；HEAD 移动提示重新确认；`index.lock` 冲突显示原文、不删锁；恢复储藏冲突时说明储藏未删除；非仓库 / 未安装 git / 工作区干净的空状态。

### 5.4 刷新
Git 页或某个项目的 Git 摘要可见、且窗口在前台时：获得焦点刷新一次，之后每 5 秒；任何写操作后立即刷新；差异窗口只在获得焦点时检查文件是否变化。

## 6. 菜单与快捷键（新增）
- 项目：Maven（⌥⌘M，打开 Maven 标签）、运行快捷操作 ▸、取消运行中的任务、Git（⌥⌘G）。
- Maven 标签内：Enter 运行选中阶段、⌘. 取消。Git 页：Space 切换暂存、Enter 打开差异、⌘↩ 提交（焦点在提交信息时）。差异窗口：F7 / ⇧F7 下一个 / 上一个改动，⌘] / ⌘[ 下一个 / 上一个文件。
- 断连时全部禁用。
