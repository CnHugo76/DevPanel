# DevPanel 产品设计 v0.2 · 2026-10-20

> 本文只写相对 [v0.1](product-design-v0.1.md) 的变更。v0.1 中没有被本文修改的约定（启停契约、日志契约、资源口径、安全边界、UI 与 CLI 共用同一管理核心等）继续有效。
> 视觉参考：[ui-mockup-v2.html](ui-mockup-v2.html)；界面规格：[ui-design-v2.md](ui-design-v2.md)。

## 1. 本版目标

v0.1 已经证明“AI 注册、人和 AI 共用同一个管理服务启停项目”这条链路可行。v0.2 解决日常使用中的三个问题：

| 问题 | v0.2 的回答 |
| --- | --- |
| Web 页面需要浏览器、登录码，不像一个常驻的工具 | 改成 **macOS 原生程序**（SwiftUI），双击即开，关窗口不影响服务 |
| 进来先看到日志，看不到全局 | 首页改为 **总览**：所有项目和服务、状态、端口、CPU、内存一屏可见；日志是点进服务后的详情 |
| profile、端口、监听地址藏在长串命令里，改起来麻烦、也看不懂 | **AI 创建选项**：AI 把常改的配置提炼成带说明的选项，人只改选项的值 |
| 不知道服务实际开了哪个端口 | 显示受管进程 **真实正在监听** 的端口，点击可在浏览器打开 |

## 2. 原生程序

- 技术：SwiftUI（必要处用 AppKit，例如大日志视图），Swift Package 构建，脚本打包为 `DevPanel.app`。代码位于 `apps/mac`。
- 与管理服务的关系不变：程序只是客户端。它读取 `<home>/daemon.json`（0600，当前用户可读）中的端口与 token，经 `127.0.0.1` 调用与 CLI 相同的 API。不再需要浏览器登录码。
- 启动程序时如果 daemon 未运行：提示并提供“启动管理服务”按钮（等价 `devpanel daemon start`），不自动启动任何项目。
- 关闭窗口：程序窗口关闭，管理服务和项目继续运行；首次关闭提示一次。
- 退出程序（⌘Q）：只退出界面，管理服务和项目继续运行。菜单中另有“停止所有服务并退出管理服务”，有运行中服务时二次确认；停止失败则报告，不假装完成。
- 系统通知：服务**非用户主动**结束（自行退出、异常、管理服务丢失运行）时发通知，例如“reg-radar · 后端 异常退出（1）”。用户主动停止不通知。
- 现有 Web 界面（`apps/ui`）在原生程序功能齐全前保留，之后退役，daemon 不再托管页面（另行决定）。

## 3. 首页总览

- 主窗口首页是所有项目的总览，项目为可折叠卡片，卡片内是服务表：服务、命令、状态、端口、运行时长、CPU、内存、操作。
- 点击服务行打开右侧详情（检查器）：日志、选项、运行记录、命令与环境。v0.1 的日志能力全部保留在详情中。
- 这一条修改 v0.1 §6.1“不设置仪表盘”的约定：总览本身就是操作界面，不是欢迎页；仍然不做监控大盘、趋势图。
- 项目标题区不放“启用开关”：它与启动 / 停止按钮的含义重叠。

## 4. AI 创建的选项

### 4.1 是什么

选项（参数）是项目里 **会被人调整的那部分配置**：Spring profile、端口、监听地址、开关型参数等。它由 AI 在注册或更新项目时创建，包含：名称、类型、当前值、可选值及各自含义、一段说明。

启动命令和环境变量通过占位符 `${key}` 引用选项。启动时由管理服务把占位符替换成当前值再执行。**选项是生成真实命令的那一层**，不是挂在旁边的注释：界面上看到的值就是实际运行使用的值。

### 4.2 三方分工

| 角色 | 能做什么 |
| --- | --- |
| AI（通过 CLI 注册 / 更新） | 读仓库后创建选项，写入值、可选值和说明；把命令中对应部分改成占位符 |
| 人（通过原生程序） | 改值；改名称和说明；删除选项（当前值写回命令）；也可以手动新增选项 |
| 管理服务 | 校验、保存、启动时替换占位符、记录每次运行实际使用的值 |

前端不预设“有哪些选项”。选项的数量和名字完全由 AI 决定；类型限定为少数几种（文本、数字、开关、单选），界面据此画控件。

### 4.3 规则

- 改选项的值只影响下次启动，界面提示“下次启动生效”，不自动重启。
- **AI 不得悄悄覆盖人改过的值。** 每个选项记录值的最后设置者（人 / AI）。AI 更新配置时，人设置过的值默认保留，除非 AI 在请求里显式要求覆盖；被保留的值会在响应中列出。
- 删除一个仍被命令引用的选项时，当前值写回命令，服务照常能启动。
- 选项可以标为敏感，规则同敏感环境变量：不回显、日志遮盖。
- 说明文字由 AI 编写，标注“AI 编写 · 日期”；人修改后标注“你修改于 …”。DevPanel 本身不调用任何模型。
- 不做：选项之间的联动 / 依赖、按环境切换的选项组、选项历史版本。

## 5. 真实端口

- 每个运行中的服务显示其受管进程 **实际在监听** 的 TCP 端口（含监听地址，用于区分“仅本机 / 所有网卡”）。
- 端口由管理服务从受管进程读取，不从配置推断；端口仍不作为进程归属的证明，也不扫描非受管进程。
- 点击端口在默认浏览器打开 `http://localhost:<port>`。

### 5.1 内存与工具资源口径（2026-10-21）

macOS “内存”采用全部已核验受管进程的 footprint 合计，RSS 保留为辅助和明确标注的回退；不可混合求和。工具底栏单独显示当前界面、管理服务与辅助进程的合计及明细，不包含业务项目。缺失/过期不冒充完整合计。详细边界见 v0.1 §9 和接口契约。

## 6. 范围外，下一批（v0.3）

- **项目任务**：跑完即结束的命令（Maven clean / install / package、`pnpm build`、测试等），由 AI 按项目登记，一键执行、看输出、可取消。不是 Maven 面板，不做依赖分析、生命周期树。
- **Git 基础能力**：改动文件列表、差异预览、暂存、提交、储藏。不做分支图、历史分析。

v0.2 的界面需为这两项预留位置（详情标签页可扩展、项目卡片可加入口），但不实现。

## 7. v0.2 验收要点

在 v0.1 §16 全部仍然成立的基础上：

| 场景 | 必须观察到的结果 |
| --- | --- |
| AI 注册含选项的项目 | 程序总览中出现选项，说明和可选值完整；命令中为占位符 |
| 人改选项值 | 当前运行不受影响，显示“下次启动生效”；重启后运行记录中的实际命令使用新值 |
| AI 再次更新配置 | 人改过的值被保留，响应列出被保留的选项 |
| 删除被引用的选项 | 当前值写回命令，服务可正常启动 |
| 服务监听端口 | 总览显示真实端口和监听地址；停止后端口消失 |
| 关窗口 / 退出程序 | 服务继续运行；重新打开程序看到同一运行 |
| 服务自行异常退出 | 收到系统通知；用户主动停止不通知 |
| daemon 未运行时打开程序 | 提示并可一键启动管理服务，不启动任何项目 |
