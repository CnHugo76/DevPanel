# v0.4.1 本地安装包

本版由用户要求打本地 tag、安装并补齐现有项目配置。未推送或创建 GitHub Release。包含 Git 文件状态颜色、列表 / 目录树 / 目录分组，以及同一 DevPanel 项目的多 Git 仓库与多个 Maven 工程。

配置字段与兼容语义见 [契约 §17](../contract/api.md#17-显式-git-仓库与-maven-工程v14-av041)，接入指引见 [配置 skill](../skills/devpanel/references/config.md)。旧配置继续使用根目录；显式目标由 AI 或用户填写，面板不递归猜目录。服务命令、参数和环境保持原样。

发布流程沿用 [v0.4 打包说明](release-v0.4.md)，版本改为 0.4.1。已验证完整 TypeScript 测试、Swift 测试、原生界面与独立运行时包。细节和本地证据见 [验收记录](plan-v0.4.md)。

升级前须备份旧 App、配置 skill 与数据目录。当前 daemon 使用 stdout 管道，重启后无法接续旧管道；有服务运行时，应明确安排短暂停服并恢复，避免留下无法接续日志的运行。数据备份在 daemon 停止后取得，敏感文件保持私有权限。只改变目标数组的配置更新不需要再次重启服务。
