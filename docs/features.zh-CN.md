# DevPanel v0.4 功能清单

[English](features.md) | **简体中文**

## 已支持功能

这里的“CLI”指 DevPanel 已有命令，不把 Agent 另行执行普通 shell 命令算作程序功能。

| 功能 | macOS 原生界面 | CLI | 使用边界 |
| --- | --- | --- | --- |
| 项目配置 | 添加、编辑、移除；多服务、工作目录、命令与环境变量 | 注册、校验、查看、列表、更新、移除 | 保存、导入、校验配置均不执行项目命令 |
| 启动选项 | 文本、数字、开关、下拉；敏感值；待生效提示 | 列出、设置、移除参数；显式保护用户值 | 下次启动生效，保存不自动重启 |
| 服务启停 | 按项目或服务启动、停止、重启；停止超时后强制停止 | `start`、`stop`、`restart`、`force-stop`、操作结果与 JSON | 托管由 DevPanel 启动的前台进程；发信号前核验进程身份 |
| 运行状态 | CPU、内存、进程数、实际监听端口、运行历史与启动快照 | `status`、`stats`、操作查询与启动报告 | 端口来自受管进程；采样不可用或过期时明确标记 |
| 日志 | 实时 / 历史、跟随、搜索、ANSI、堆栈折叠、原文复制与可选前缀精简 | tail、follow、JSON、`--after-seq` 增量读取 | 精简部分常见 Spring Boot / Logback / Log4j 格式；未知格式保留原文 |
| 就绪判断 | 编辑日志文字或监听端口条件；显示结果、用时与证据 | `start` / `restart --wait-ready` 与启动报告 | 只判断一次；超时标记结果，不停止或重启服务 |
| 日志摘要 | 复制当前查看运行的摘要 | `logs --digest`、字节预算与增量读取 | 确定性压缩错误、堆栈、重复与末尾日志，不调用模型、不诊断原因 |
| 来源与动态 | 启停发起方、项目时间线、脱敏配置差异 | `--agent`、`DEVPANEL_AGENT`、`activity` | Agent 名称为自报；动态不提供配置回滚 |
| 人工接管 | 修改规则、人工停止后暂停、允许 AI 启动、锁定 / 解锁 | 读取规则与状态，启停命令受规则约束，显式 `--override-hold` | 规则只覆盖服务启停；快捷操作、Maven 与选项修改不在规则范围 |
| 快捷操作 | 配置、运行、取消；输出、历史、资源与可选时限 | `action list`、`action run`、`task cancel` | 同一操作同时最多一次，不同操作可以并行 |
| Maven | 模块 / 生命周期树、目标、Profiles、跳过测试、离线、构建依赖模块、命令预览、存为快捷操作 | `maven modules`、`maven run`、选择工程与取消任务 | 显式登记多个根目录；静态解析 POM；同一 DevPanel 项目同时最多一个 Maven 运行 |
| Git | 分支 / 上游 / 领先落后、改动分组、状态颜色、三种文件布局；并排 / 统一独立差异窗口与行内高亮 | 没有专用 Git 命令 | 文件暂存 / 取消暂存、提交 / amend、stash 保存 / 列表 / apply / pop 由原生界面操作 |
| 服务与工具关联 | 从所选服务打开对应 Git 仓库或 Maven 工程 | 在项目配置中登记仓库 / Maven 路径 | 按服务工作目录匹配已登记的最深父目录，不递归发现工程 |
| 桌面与安装 | 总览 / 详情、快捷键、后台事件通知、CLI 安装、可选登录启动 | daemon 启动 / 停止 / 状态 / 安装 / 卸载 | 关闭界面不停止服务；完整 App 内置 Node、daemon、CLI 与采样器 |

## 当前限制

- 支持 macOS 14 及以上；原生界面目前主要为简体中文，中英文仓库介绍不代表界面已支持多语言。
- 不接管已有进程，不管理远程主机或容器，不做自动重启、HTTP 就绪探测、持续健康检查与服务依赖编排。
- 暂停和锁定用于防止 CLI 误操作，不构成同一系统用户下的安全边界。默认禁止 AI 强制停止，锁定只能在界面解除。
- daemon 重启后无法重新接上旧 stdout 管道。无法恢复的运行会显示未知与日志缺口，不保证无缝恢复。
- Git 不支持 fetch / pull / push、分支管理、丢弃修改、冲突解决或按行暂存。提交钩子输出在提交结束后显示。
- Maven 是静态模型，不是 Maven effective model；没有依赖图、插件浏览器或 Gradle 面板。
- 发布包使用 ad-hoc 签名，不做开发者签名、公证、自动更新或包管理器分发。Intel 打包与干净 Mac 的完整安装流程仍需验证。

## 建议的 v0.4 优化顺序

以下为建议，尚未全部实现，也不是已批准的开发任务。

| 优先级 | 调整 | 完成标准 |
| --- | --- | --- |
| P0 | 发布前核验 Swift 工具链兼容性 | 首次完成的公开 [CI](https://github.com/CnHugo76/DevPanel/actions/runs/40162240195) 暴露 `UNNotificationSettings` 跨隔离域问题。通知投递现改为在系统回调读取设置，只传递授权状态枚举；每个候选版本打标签前检查[最新 CI 结果](https://github.com/CnHugo76/DevPanel/actions/workflows/ci.yml) |
| P0 | 版本与发布证据对齐 | 选定版本，统一包 / App 元数据，写清相对 `v0.4.1` 的变化，从明确的公开提交构建，保证标签、产物与校验文件对应 |
| P0 | 补齐安装验收 | 使用隔离数据验证 Gatekeeper、CLI PATH、覆盖确认、移动 App、登录启动、通知、升级与卸载；逐一验证承诺提供的架构 |
| P1 | 补齐中英文首次使用路径 | 新用户按一篇短指南完成安装或构建、添加 demo、配置就绪、启动、看输出、停止；缺工具 / PATH / 就绪条件时有明确下一步 |
| P1 | 让状态与接管提示更便于处理 | 运行中、等待、已就绪、超时、未知分别给出证据与下一步；暂停 / 锁定原因、配置下次启动生效清楚可见 |
| P1 | 加强日志与后台行为验证 | 用代表性日志格式和大输出验证搜索、折叠、导航与原文复制；复测隐藏窗口、后台与断连时的资源占用 |
| P2 | 分步扩展语言覆盖 | 先翻译 demo 与常用指南；原生界面另行规划本地化，维护一致术语与翻译检查 |

建议 v0.4 优先把安装可靠性、状态表达和日常使用打磨完整。远程执行、容器编排、自动恢复和更完整的 Git 客户端需要单独的产品决策；涉及 API 的调整仍按仓库契约提案流程进行。
