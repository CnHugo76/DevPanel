# DevPanel 原生界面设计 v2

> 产品依据：[product-design-v0.2.md](product-design-v0.2.md)（以及仍然有效的 v0.1）。视觉参考：[ui-mockup-v2.html](ui-mockup-v2.html)（HTML 画的设计稿，实现用 SwiftUI）。
> 数据字段只来自契约（`contract/api.md`、`packages/contract`）；界面不显示契约里没有的“事实”。v1 的 [ui-design.md](ui-design.md) 中关于日志、状态文案、断连、缺失值的规则继续适用，本文只写原生程序的结构和新增部分。

## 1. 技术与工程

| 项 | 决定 |
| --- | --- |
| 位置 | `apps/mac`（Swift Package；可执行目标 `DevPanel`，库目标 `DevPanelKit` 放模型、网络、状态，便于测试） |
| 最低系统 | macOS 14 |
| UI | SwiftUI 为主；日志视图用 AppKit `NSTextView`（TextKit 2）包装，保证 5 万行级别滚动与选择流畅 |
| 状态 | `@Observable` 的单一 `AppModel`，由事件流驱动；视图不直接发网络请求 |
| 网络 | `URLSession`：普通请求 + `bytes(for:)` 读 SSE；地址和 token 来自 `<home>/daemon.json`；所有变更请求带 `X-DevPanel-Client: ui` |
| 契约类型 | Swift `Codable` 类型逐一对应 `packages/contract`；用 mock-daemon 录制的 JSON 做解码测试，防止漂移 |
| 打包 | `apps/mac/scripts/bundle.sh` 生成 `DevPanel.app`（Info.plist、图标、ad-hoc 签名） |
| 测试 | Swift Testing：解码、状态映射、日志缓冲、选项替换预览等纯逻辑 |

## 2. 窗口结构

```
┌ 工具栏 ───────────────────────────────────────────────────────────────┐
│ ●●●  [D] DevPanel  ● 已连接 · 4/7 服务运行中        [⌕ 搜索]  [＋ 添加项目] [⋯] │
├──────────────────────────────────────────┬─────────────────────────────┤
│ 总览（滚动）                               │ 检查器（选中服务时出现，可拖宽） │
│ ┌ 项目卡片 ────────────────────────────┐ │ 后端 ● 运行中        ■ ↻ ✕   │
│ │ ⌄ reg-radar  2/2 运行中  ~/路径   CPU · 内存  ▶ ■ ↻ ⋯ │ │ 运行 · PID · 时长 · 资源       │
│ │ ✦后端配置 dev ▾  ✦API 端口 8081 ▾  ＋选项 │ │ [日志][选项][运行记录][命令与环境]│
│ │ 服务 命令 状态 端口 时长 CPU 内存 操作      │ │                              │
│ └──────────────────────────────────────┘ │                              │
└──────────────────────────────────────────┴─────────────────────────────┘
```

- 默认窗口 1180×760，最小 900×560。检查器宽度 380–640，默认 470，记住上次宽度。
- 跟随系统浅色 / 深色；强调色紫色（深色 `#7c6cf6`，浅色 `#6656e8`），状态色沿用 v1 语义。
- 工具栏搜索：按项目名、服务名过滤总览（只过滤显示，不改变顺序）。

## 3. 总览

### 3.1 项目卡片
- 标题行：折叠箭头、项目名、聚合状态徽标（`2/2 运行中` / `部分运行 1/2` / `异常` / `已停止` / `状态未知`）、路径（等宽小字，点击在 Finder 中显示）、项目合计 CPU · 内存（有运行时）、▶ 启动全部、■ 停止全部、↻ 重启、⋯（编辑项目、复制项目 ID、复制 Agent 规则、移除项目）。
- 选项行：项目的选项以小标签显示（§5.1）；没有选项时不显示这一行，只在 ⋯ 菜单里提供“添加选项”。
- 折叠状态按项目记住。顺序为注册顺序，状态变化不重排。

### 3.2 服务表
| 列 | 内容 | 宽度 |
| --- | --- | --- |
| 服务 | 进程色点 + 名称；下方小字提示（“选项已修改 · 下次启动生效”“退出（1）· 10:42”） | 16% |
| 命令 | 等宽、单行截断；占位符原样显示 `${profile}`，悬停显示替换后的完整命令 | 弹性 |
| 状态 | 状态胶囊：图标 + 文字（v1 §3 的状态表） | 15% |
| 端口 | 真实监听端口胶囊 `8081 ↗`；仅监听本机时直接显示，监听所有网卡时附“局域网”小标；无运行时“—” | 10% |
| 运行时长 / CPU / 内存 | 右对齐、等宽数字；缺失值规则同 v1（采样中 / 部分 / 不可用，绝不显示 0） | 9% / 8% / 9% |
| 操作 | ▶ / ■、↻、⋯；停止超时时替换为红色“强制停止” | 96pt |

- 各卡片列宽一致（固定列宽），上下对齐。
- 进程色点：按服务在项目内的顺序从固定 8 色调色板取色，日志视图中沿用同一颜色。
- **紧凑模式**：检查器打开时隐藏“命令”和“运行时长”两列、隐藏路径，保证 CPU / 内存完整显示。继续变窄时先缩小状态与端口列，再隐藏端口；内存列保留 RSS 回退后缀所需宽度。
- 点击行选中并打开检查器；双击行等同“打开日志”；⌘↩ 启动 / 停止选中服务（二次按下不重复发送）。

## 4. 检查器（服务详情）

- 头部：色点、服务名、状态胶囊、■ / ▶、↻、✕ 关闭；下一行为项目名 · 运行 ID（短）· PID · 运行时长 · CPU · 内存（footprint；缺失时明确标注 RSS 回退）· 进程数。
- 标签页：**日志**、**选项**、**运行记录**、**命令与环境**。标签栏为可扩展结构，v0.3 将在这里加入“任务”“Git”。

| 标签 | 内容 |
| --- | --- |
| 日志 | v1 §5.4 的全部规则：当前 / 历史运行切换、搜索（⌘F）、跟随、新日志提示、ANSI、stderr 红线、`sys` 行、截断与采集中断提示 |
| 选项 | 本服务引用到的选项列表（§5.3）；以及“＋ 添加选项” |
| 运行记录 | 最近 3 次运行：开始 / 结束时间、退出原因、退出码 / 信号、**当次实际使用的选项值** 与替换后的命令 |
| 命令与环境 | 命令（带占位符）、工作目录、环境变量（敏感值隐藏）、停止等待秒数；可编辑，保存规则同 v1 §6 |

## 5. 选项

### 5.1 选项标签（总览）
- 形如 `✦ 后端配置 dev ▾`：✦ 表示由 AI 设置；人改过的不显示 ✦。
- 值已修改但对应服务还在用旧值运行时：标签边框虚线 + 琥珀色圆点，悬停提示“已修改，下次启动生效”。
- 敏感选项值显示为 `••••`。
- 点击弹出编辑弹窗（§5.2）。

### 5.2 编辑弹窗
- 标题：选项名称；副标题：`✦ AI 编写 · 10/20` 或 `你修改于 11:02`。
- 说明文字（选项的 `description`）。
- 控件按类型：

| 类型 | 控件 | 说明 |
| --- | --- | --- |
| `enum` | 单选列表，每项显示值、标签和该值的说明 | 选项 ≤ 4 个且无说明时可用分段控件 |
| `string` | 单行文本框 | 等宽字体 |
| `number` | 数字框 + 步进器 | 有 `min` / `max` 时校验 |
| `boolean` | 开关 | |

- 底部：“删除此选项”、提示“改动在下次启动时生效”、“完成”。值改动即时保存（带 revision；冲突时提示“配置已被其他客户端修改”并刷新）。
- 不提供“保存并重启”。

### 5.3 选项列表（检查器“选项”标签）
- 每个选项一张卡片：名称、`${key}`、设置者与时间、说明、控件、引用位置（“用于：后端 命令 `-Dspring-boot.run.profiles=${profile}`”）。
- “＋ 添加选项”：人手动新增，需填写 key、名称、类型、值；可选说明和可选值。
- 名称和说明可直接编辑；编辑后设置者变为“你”。

### 5.4 删除
- 选项未被引用：直接确认删除。
- 选项被引用：确认框展示删除后的命令 / 环境（当前值写回，用绿色标出），按钮“删除并写回”。

## 6. 添加 / 编辑项目
- 以窗口内 sheet 呈现：项目名称、根目录（原生“选择…”面板）、服务列表（名称、ID、工作目录、命令、通过 Shell 运行、环境变量、停止等待）、选项列表。字段与 v1 §6 相同，并修正 v1 已知问题：复选框点击区域仅限控件与文字；控件位置不随预览变化跳动；标题与输入框关联。
- 命令输入下方实时显示替换后的预览（使用当前选项值），引用了不存在的选项时红字提示。
- 校验、冲突、敏感值规则同 v1。

## 7. 程序级行为
- **daemon 未运行**：总览区显示“管理服务未运行”和“启动管理服务”按钮；工具栏状态为灰色。
- **断连**：工具栏状态变琥珀色并显示重连倒计时；总览顶部黄条“下面是 hh:mm:ss 的状态，可能已过期”；状态与资源变灰；操作禁用。规则同 v1 §9。
- **首次关闭窗口**：提示“DevPanel 会在后台继续管理项目，可从 Dock 重新打开”。
- **菜单**：
  - DevPanel：关于、停止所有服务并退出管理服务…、退出 DevPanel（⌘Q，仅退出界面）。
  - 文件：添加项目（⌘N）、移除项目。
  - 服务：启动 / 停止 / 重启选中服务、强制停止、打开日志（⌘L）。
  - 窗口：显示检查器（⌥⌘I）。
- **不提供“设置”菜单**：v0.2 目前没有可由用户配置的程序级设置；删除空入口，避免暗示存在未实现的设置窗口。布局偏好由现有显示操作保存，不另设空页面。
- **通知**：仅对非用户主动结束发送（`exit.reason` 为 `self-exit` 且失败、`daemon-lost`，或进入 `unknown`）；点击通知打开对应服务的日志。首次需要时请求通知权限。
- **Dock 图标**：有服务异常时显示角标数字。

## 8. 空状态与文案
- 无项目：图标、“还没有项目”、“在项目里对你的编程 Agent 说「把这个项目加入 DevPanel」。它会读懂启动方式，把常改的配置做成选项并写好说明。”、CLI 示例、“手动添加项目”按钮。
- 其余文案、状态词、禁止用语沿用 v1 §3。

## 9. 不做（v0.2）
菜单栏常驻图标、多窗口、自定义主题、日志导出、资源趋势图、项目任务（v0.3）、Git（v0.3）。


## v0.2 交互补充：详情模式与按需说明（2026-10-20）

依据用户在真实项目使用后的反馈，以下覆盖前文冲突的展示要求：

- 顶栏提供“总览 / 详情”；详情使用 220 pt 服务导航，其余宽度交给同一检查器。切换布局保留服务、运行、搜索和日志文本视图。总览继续支持旁侧预览；900 pt 窄窗口下优先保留服务、状态、CPU、内存和操作；端口列先收窄，再隐藏，可在详情查看。服务 CPU/内存不再由项目汇总代替。
- 选项默认仅名称、值与问号入口。enum 使用下拉，number 使用输入与步进器。说明、编写者、取值说明、范围、引用与编辑/删除入口收进问号展开区域；错误与冲突仍直接显示。下次启动生效在页级提示一次，弹窗保留该提示。
- 日志按连续堆栈行折叠为可点摘要，保留异常标题与原因链。搜索覆盖原文、命中自动展开、复制包含隐藏原文。顶部“折叠”可切换全部展开/收起。不同错误不做去重。
- 无契约与 daemon 改动。App 重新打包后需退出并重开界面；后台服务无须重启。

## v0.2 资源与选项分组补充（2026-10-21）

- 所有内存展示优先 footprint，缺省时标注 RSS；不混合两种口径，未知值不显示 0。项目与服务统计包含全部已核验进程。
- 窗口底栏显示“工具”CPU/内存，展开显示界面、管理服务、辅助进程及合计；业务项目不计入。断连、超过 6 秒或分项缺失时提示部分可用/过期。
- 总览选项按使用范围分为公共、单服务、未引用组；同一选项只出现一次。分组仅用于展示，不引入产品范围外的环境切换或联动。窄窗口选项自行换行。
